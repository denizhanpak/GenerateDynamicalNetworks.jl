GenerateDynamicalNetworks

Given a transition graph and the mean time spent in each state, this package builds a noisy dynamical system whose switching between states reproduces both. You say which states follow which, with what probability, and how long each lasts on average; a backend builds the system, and the package then measures it against what you asked for.

Installation

The package isn't registered yet. Install it from its repository:

using Pkg
Pkg.add(url="https://github.com/denizhanpak/GenerateDynamicalNetworks.jl")

A short example

using GenerateDynamicalNetworks

P = [0 1 0; 0 0 1; 1 0 0]                    # state 1 → 2 → 3 → 1
spec = TransitionSpec(P, [1.0, 3.0, 10.0]; noise=1e-3)

model = fit(spec, Horchler())                # a Lotka–Volterra network
accept(model, spec)                          # dwells and branches on held-out runs
classify(model, spec)                        # (class = :heteroclinic, …)
runs = simulate(model, spec; T=500)          # the states visited and when

A three-state ring goes through this example step by step.

Backends

Seven constructions are included. Each is a type passed to fit.

BackendTypeThe system it builds
HorchlerHorchlerLotka–Volterra network, one node per state, designed in closed form
SimplexSimplexone cell per state with cubic coupling
CylinderCylinderone position variable for the state and one cell per edge
Two-populationTwoPopulationone cell per state and one per edge, in two coupled populations
CTRNN designCTRNNDesigncontinuous-time recurrent neural network with relay cells
SynchronySynchronypairs of phase oscillators, with states at patterns of in-phase and anti-phase pairs
HopfieldHopfieldHopfield network with states at the vertices of a cube

Each backend is labelled stable or experimental by how it does on the benchmark suite: every backend is run on the example networks at two noise levels and put through the acceptance protocol (The acceptance rule). The table is built from the stored runs; Results has every case.
