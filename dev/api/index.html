GenerateDynamicalNetworks.GenerateDynamicalNetworks — Module
GenerateDynamicalNetworks

Build a noisy dynamical system whose switching between states reproduces a given transition graph and mean dwell times. The core layer here holds the specification (TransitionSpec), example networks, one frame-based stochastic simulator shared by every backend (simulate), the measurement and acceptance rules (measure, verdict, validate, accept) and the dynamical classifier (classify). Backends plug in by subtyping AbstractNetworkModel.

GenerateDynamicalNetworks.AbstractNetworkModel — Type
AbstractNetworkModel

A model a backend builds. A subtype M supplies these methods, and simulate, validate, accept and classify then work on it:

methodreturns
drift_function(m::M)the drift f(u, q, t) of du = f(u, q, t) dt + g(u, q, t) dW
parameters(m::M)the parameter NamedTuple q passed to f and g
initial_state(m::M)the starting state, an SVector
speed(m::M)the fastest rate in the model; the step is at most dtscale / speed(m)
frame_state(m::M, q, u)the state read at a frame: an index in 1:nstates, or 0 to keep the last one

and optionally

methoddefault
noise_function(m::M)flat_noise, the same amplitude q.ε on every variable
in_bounds(m::M, u)maximum(abs, u) < 100; a run that leaves is stopped and marked failed
project(m::M, u)nothing; otherwise the state is replaced by its return value after every step
class_state(m::M, q, u)frame_state(m, q, u); what classify reads, where values ≤ 0 are ignored
class_start(m::M)initial_state(m); where the classifier's noisy run starts

GenerateDynamicalNetworks.CTRNNDesign — Type
CTRNNDesign(; by_state=true, passes=10, late_runs=192, base=100_000)

The CTRNN backend's edge-by-edge design: one cell per state plus one relay cell per two-way pair, each edge's weight solved from a 1-D first-passage time, then correction passes from measured rates (see ctrnn_correct_offsets; by_state=false uses 8 passes and 96 late runs by default). Seeds start at base, so different bases give independent fits.

fit(spec, CTRNNDesign(); checkpoint=nothing, deadline=Inf, verbose=false) -> CTRNNModel
Status: stable

Passes the acceptance protocol on most of the benchmark cases; see the Results page of the documentation.

GenerateDynamicalNetworks.CTRNNModel — Type
CTRNNModel

A continuous-time recurrent network τ ⊙ dy = (−y + W σ(g(y + b))) dt + τ ⊙ ε dW per cell, written dy = (−y + W σ(g(y + b))) ./ τ dt + ε dW, with σ the logistic function. The first visible cells are the states, read by the largest g(yᵢ + bᵢ); any after them are hidden relay cells. α[1] is the stiffest rate, which sets the step. Built by fit(spec, CTRNNDesign()), or from a parameter vector with CTRNNModel(spec, θ).

source
GenerateDynamicalNetworks.CTRNNModel — Method
CTRNNModel(spec, θ; cap=Inf)

The model with parameters θ = [vec(W); b; log τ; log g] over all N cells (so length(θ) == (N+1)²), as ctrnn_parameters returns them. Throws an ArgumentError if the stiffest rate is above cap.

GenerateDynamicalNetworks.Cylinder — Type
Cylinder(; k=2.0, Lω=1.5625, pwindow=0.25, ywindow=0.5, passes=4, runs=16, T=nothing, budget=500, popsize=12,
         seconds=300.0)

The cylinder backend's fit (Ashwin & Postlethwaite 2013): one global speed and a rate per edge (CylinderModel), with steepness k, Lω and the decoder windows pwindow and ywindow fixed, one shared noise, no hidden states. A seed from the Horchler dwell design (edge_seed_rates), passes correction passes of runs runs of length T (default 125Στ), and if the best of those fails a check on 32 held-out runs, a CMA-ES search over the speed and edge rates of at most budget evaluations or seconds seconds, then two correction passes as a polish. (The prototype stopped at 420 s by default.) A binding time limit makes the result depend on the machine's speed; seconds=Inf limits the search by budget alone.

fit(spec, Cylinder(); verbose=false) -> CylinderModel
Status: experimental

Fails the acceptance protocol on half or more of the benchmark cases; see the Results page of the documentation.

GenerateDynamicalNetworks.CylinderModel — Type
CylinderModel{N}

Ashwin & Postlethwaite's cylinder network on a graph with N edges: edge cells y and a phase p, at speed s, with Lα[m] for edge m (from[m] → to[m]), steepness k and Lω. Read as state j when |p − j| < pwindow and every |y| < ywindow; otherwise the last state holds. Built by fit(spec, Cylinder()) or CylinderModel(spec, θ).

GenerateDynamicalNetworks.HopModel — Type
HopModel

A Hopfield network of n neurons in phase form, ψ̇_j = sin ψ_j (k_j cos ψ_j − b_j − Σ_m J_jm cos ψ_m), with the graph's states on vertices of the cube: node_of[v] is the state at vertex v (0 for transits and unused vertices) and corner_of[i] the vertex of state i. α bounds every rate, for the step. Built by fit(spec, Hopfield()) or HopModel(spec, out).

GenerateDynamicalNetworks.Hopfield — Type
Hopfield(; passes=12, base=100_000)

The Hopfield backend's fit. The layout (hop_layout) puts states on vertices of the cube of the fewest neurons whose pairwise design works. Every edge's departure rate starts from the race of each state's 1-D exits (hop_seed), which also gives the starting response; then passes correction passes (correct_rates) with every rate capped at 2× the contraction. The transit rate and contraction are 4× the largest rule-of-thumb rate. If a pass's rates have no pairwise design, the fit warns and returns the last pass that had one.

fit(spec, Hopfield(); checkpoint=nothing, deadline=Inf, verbose=false) -> HopModel
Status: stable

Passes the acceptance protocol on most of the benchmark cases; see the Results page of the documentation.

GenerateDynamicalNetworks.Horchler — Type
Horchler(form=:u; passes=4, runs=16, T=nothing, budget=500, popsize=12, seconds=300.0)

The Horchler backend's fit, in the :u form (the default) or the :x form of LVModel. The closed-form design (horchler_design) gives the first model; passes correction passes of runs runs of length T (default 125Στ) adjust the dwells it is asked for. If the best of those fails a check on 32 held-out runs, a CMA-ES search over every node's α and ν of at most budget evaluations or seconds seconds, then two polish passes on ν (polish_saddles). (The prototype's search had no time limit.) A binding time limit makes the result depend on the machine's speed; seconds=Inf limits the search by budget alone.

fit(spec, Horchler(); verbose=false) -> LVModel

Throws an ArgumentError if the graph can't be repaired, or if no dwell request has a design (the noise is too large for the dwells: the :x form needs far less noise than the :u form).

Status: stable

Passes the acceptance protocol on most of the benchmark cases; see the Results page of the documentation.

GenerateDynamicalNetworks.LVModel — Type
LVModel(form, P, visible, κ, β, α, ε, ρ)

A Lotka–Volterra network. In the :u form, du = u ⊙ (α − ρ(u ⊙ u)) dt + ε ⊙ dW, with activity x = u²; in the :x form, dx = x ⊙ (α − ρx) dt + ε ⊙ dW, put back to x ≥ 0 after every step. Deterministically the two are the same system, with every rate doubled in the u form. P is the graph the model was built on: its first visible states are the specification's, the rest hidden states added by repair. A frame is read as the state of largest |u|; a frame won by a hidden state keeps the last visible state. Runs start near node 1 at (1 − κ)β₁. Built by fit(spec, Horchler()).

GenerateDynamicalNetworks.SyncModel — Type
SyncModel

Phase oscillators in M pairs with the graph's states on corners of the S/D cube: Λ[σ, v] is the rate in direction σ at corner v (corner v − 1 has bit σ − 1 set when pair σ is anti-phase), node_of[v] the graph state at corner v (0 for transits and unused corners) and corner_of[i] the corner of state i. α is the stiffest rate, for the step. GenerateDynamicalNetworks.Synchrony — Type
Synchrony(; seed=:rough, passes=12, base=100_000)

The synchrony backend's fit. The layout (sync_layout) puts states on corners of the S/D cube of the fewest oscillator pairs that work. Every edge's departure rate starts from the rule of thumb log(1/ε)/τᵢ · √(Pᵢⱼ · out-degree) (seed=:rough), or from the 1-D race of each state's exits solved for its dwell and shares, which also gives the starting response (seed=:race). Then passes correction passes (correct_rates); the transit rate and contraction are 4× the largest rule-of-thumb rate.

fit(spec, Synchrony(); checkpoint=nothing, deadline=Inf, verbose=false) -> SyncModel
Status: stable with `seed=:rough`, experimental with `seed=:race`

With the default seed it passes the acceptance protocol on most of the benchmark cases; with the race seed it fails half of them. See the Results page of the documentation.

GenerateDynamicalNetworks.TransitionSpec — Type
TransitionSpec(P, τ; noise, sample=minimum(τ)/10, names=["state 1", …])
TransitionSpec(g::SimpleDiGraph, τ; kwargs...)

What a model has to reproduce: the transition matrix P (P[i, j] is the probability that a visit to state i is followed by j), the mean dwell τ[i] in each state, the noise level noise, and sample, the interval at which the decoder reads which state the system is in. A graph alone means every branch out of a state is equally likely. Throws an ArgumentError listing every problem found by spec_problems.

TwoPopModel{N}

Ashwin & Postlethwaite's two-population network on a graph with N edges: state cells p and edge cells y, at speed s, with B[k] = 1.5 − ν[k] for edge k (from[k] → to[k]). Read by the state cell of largest |p|. Built by fit(spec, TwoPopulation()) or TwoPopModel(spec, θ).

GenerateDynamicalNetworks.TwoPopulation — Type
TwoPopulation(; passes=4, runs=16, T=nothing, budget=500, popsize=12, seconds=300.0)

The two-population backend's fit: a seed from the Horchler dwell design (edge_seed_rates), passes correction passes of runs runs of length T (default 125Στ) on the heteroclinic side, and if the best of those fails a check on 32 held-out runs, a CMA-ES search over the signed ν (either side of the bifurcation) of at most budget evaluations or seconds seconds, then a short polish if every ν is still negative. GenerateDynamicalNetworks.classify — Method
classify(m, spec; Tnoisy=40sum(spec.τ), Tfree=150sum(spec.τ), starts=5, ghost_ratio=100) -> (; class, outcomes)
classify(f, q, z0, decode; noise, Tnoisy, Tfree, dt, starts=5, ghost_ratio=100) -> (; class, outcomes)

The dynamical class of a model: :heteroclinic, :excitable, :ghost, :limit_cycle or :unknown. A noisy run of length Tnoisy at the specification's noise gives starts − 1 points from its second half, plus the start itself; a noise-free run of length Tfree from each ends in one of

  • a stable equilibrium → excitable;
  • a saddle, or cycles that keep growing (each over 1.2× the one before) → heteroclinic;
  • a repeating cycle → ghost if its peak speed is at least ghost_ratio times its slowest, else limit cycle;
  • anything else → unknown.

The class is unknown unless every start agrees. outcomes describes each start's run. The second form classifies any vector field f(u, q, t) with a decoder decode(u) (values ≤ 0 are ignored), stepped at dt.

Dwell statistics pooled over runs from simulate. GenerateDynamicalNetworks.score — Method
score(runs, spec; off_free=0.005, off_weight=5.0) -> (; f, dwell, off, branch_term, dwell_term)

The fitting objective: Σ log(measured dwell / τ)², each term capped at 25 (35 for a state never visited), plus Σ log(measured / designed share)² over the branches of states with two or more successors, plus off_weight per unit of off-graph share above off_free. A set with a failed run scores 1000. spec needs fields P and τ.

GenerateDynamicalNetworks.simulate — Method
simulate(m, spec; T, seeds=1:16, dtscale=0.01)
simulate(m; T, seeds, sample, dtscale=0.01)

Independent runs of model m for time T, one per seed, in parallel over threads. Each returns (; state, t, failed): the states entered, read once per frame of length sample (the specification's), the times they were entered, and whether the run left the model's bounds. The step is the largest no coarser than dtscale / speed(m) that lands on every frame. A run depends only on its seed, not on the number of threads.

GenerateDynamicalNetworks.spec_problems — Method
spec_problems(P, τ, noise) -> Vector{String}

Every reason (P, τ, noise) is not a valid specification, in plain words; empty if it is valid. P[i, j] is the probability that a visit to state i is followed by a visit to j, so rows sum to

  1. Every dwell must be positive, the noise must be positive (noise-free dwell times are not set),

and every state must be reachable from every other.

GenerateDynamicalNetworks.verdict — Method
verdict(meas, P, τ; tol=0.05) -> (; err, branch, off, pass)

The acceptance rule on one set of runs: every mean dwell within tol of τ (err holds the relative errors), every branch of a state with two or more successors inside the 95% binomial interval around its designed probability (branch holds one (; from, to, designed, measured, ok) per such edge), and fewer than 1% of transitions off the graph (off).
